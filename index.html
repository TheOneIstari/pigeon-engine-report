Pigeon Engine

A lightweight reusable Three.js render engine shell with a fun low-poly pigeon demo. The point is not just “look, a bird,” but a clean structure you can reuse for future scenes, mascots, landing pages, or playful 3D UI moments.

What this includes

  • A compact render loop with scene, camera, renderer, resize handling, lights, and update tick.
  • A demo asset built from primitive geometry so it stays easy to understand and fast to render.
  • A structure that can be extracted into a reusable mini-engine for future 3D components.

Why the pigeon

Because it’s funny, friendly, and slightly absurd — which makes it memorable. Also, a pigeon is a decent stress test for stylized organic shapes without needing a heavy model pipeline.

Engine shape

Keep a small createEngine(canvas) core that owns renderer setup, animation ticks, and resize logic. Scene-specific code plugs into that shell.

Performance notes

Primitive meshes, a tiny material set, one directional light, one hemisphere light, capped pixel ratio, and zero texture I/O keep the cost low.

Reuse potential

The same setup could drive mascots, logo scenes, product explainers, hero headers, or micro-games without changing deployment complexity.

Built as a public report/demo page. You can lift the engine structure and swap the pigeon out for literally anything else.
